## 适用对象

- 报考华北电力大学（北京）核科学与工程学院相关方向的复试考生

- 想快速梳理金属结构、相图、热处理、缺陷、性能与腐蚀等知识点的学习者

## 复习范围概览

根据考试大纲，复习重点主要包括：

- 金属结构：原子键合、典型晶体结构、非晶态、晶向/晶面指数、合金相结构
- 结晶与组织：纯金属结晶、合金概念、铸锭组织特征
- 相图：匀晶、包晶、共晶、共析相图，铁碳合金相图，杠杆定律
- 塑性变形与再结晶：塑性变形机制、冷变形影响、回复与再结晶
- 固态相变与热处理：扩散型/非扩散型相变，奥氏体形成，珠光体、马氏体、贝氏体和回火转变
- 晶体缺陷：点缺陷、位错、位错运动、表面与界面
- 力学性能：硬度、强度、蠕变、疲劳、冲击性能
- 腐蚀性能：均匀腐蚀、电偶腐蚀、磨蚀、应力腐蚀等

## 推荐使用方式

1. 先阅读考试大纲，明确复试范围和知识边界。
2. 按“概念题、填空题、简答题、分析题”分类整理知识点。
3. 使用回忆版题目自测，标记不会或容易混淆的概念。
4. 回到教材和课堂笔记补充推导、图示和典型例题。
5. 复试前整理一份高频名词解释和相图/热处理流程速查表。
